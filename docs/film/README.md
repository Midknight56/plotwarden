# Film props

Three pictures made for the film. They are not part of the registers, and the site does not load them.

| File | What it shows | How it was made |
|---|---|---|
| `book-page.webp` | Page 3 of an invented book of burials for Lantern Fold, Yew Walk, with eight handwritten rows | Drawn in HTML and SVG, then saved as a picture with headless Chromium |
| `garden-plan.webp` | An invented plan of the beds of a lower garden, copied from an old survey: 22 numbered beds, a main walk, an old curved walk, a shed, a tap and a gate | Drawn in SVG, then saved as a picture with headless Chromium |
| `stone-face.webp` | The invented headstone of Mirel Quillmoss of Hollowmere, keeper of the Lantern Fold, in grass, with one worn line | Built and rendered in Blender 5.2 from a Python script: the stone, the cut letters, the lichen, the grass and the light |

Fonts drawn into the pictures: Gochi Hand, Spectral and Almendra SC. Each one is under the SIL Open Font License 1.1.

Lantern Fold, Hollowmere, the Lower Garden and every name and date in these pictures are invented. No photograph, stock picture, real map or real grave was used.
