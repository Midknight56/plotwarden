# Rights

## Licence

The code is MIT licensed. See `LICENSE`. Notices for the packages that ship are in `THIRD_PARTY_NOTICES.md`, and `npm run check:licenses` fails when a package that ships in the apps or in the Review Desk preview has no row there, or a row with another version or licence than the package states.

## Art

Every drawing in `assets/` was drawn for this project as SVG paths. None is traced from a photograph, a stock library, a logo or a font. `assets/origins.md` lists each file with its origin and where it is used, and `tests/unit/copy.test.ts` fails if a file in `assets/` is not listed. The drawings hold no text and no script.

No real grave, scanned official form, personal record or stock logo is used anywhere.

## People and places

Lantern Fold and Thimble Beds are invented places. Every person, burial, inscription, reservation, tenancy and payment in them was made for this project, and none is a real person. The same is true of the stalls and traders of the market example. Practice registers are kept apart from a keeper's own records.

The two sample visitor files on the site are built from those invented registers by the same code that a keeper uses. They hold only the one invented name that the invented warden approved, or free plot codes.

## Names

"Plotwarden", "Churchyard Register", "Allotment Register" and "Plotwarden Review Desk" are the names of this project. Kiro is the tool that wrote the code and the tests, and `docs/kiro-evidence.md` says how.

## What was not cleared

- No real person was asked to take part, so no consent was needed or collected.
- No third party font, image or script is used by the site. The page fonts are the fonts already on the reader's device.
